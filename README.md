O projeto PetDot foi desenvolvido com o objetivo de criar uma solução web simples e funcional para apoiar o processo de adoção de animais, centralizando informações por meio de um sistema organizado e intuitivo.

A aplicação foi construída com HTML, CSS e JavaScript, integrando um banco de dados SQLite por meio do Sequelize ORM. O sistema permite a realização completa das operações de cadastro, edição e exclusão de dados (CRUD). Ao todo, foram implementadas 5 entidades principais no formulário, incluindo nome, telefone, e-mail, CPF e relato, com validações básicas para padronização das informações. Foram desenvolvidas rotas específicas utilizando o método POST. Projeto feito em aula, conseguindo 90% em aprovação!
